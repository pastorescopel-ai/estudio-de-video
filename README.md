# Estúdio de Vídeo

Versão atual: **1.7.8**

O Estúdio agora procura atualização sempre que a janela é aberta (antes só procurava a cada 6 horas) e mostra a versão na tela inicial, com um botão para procurar na hora. Inclui também os GIFs do GIPHY e os sons mais baixados do Freesound.

- Instalar num PC novo: baixe `EstudioDeVideo-Instalador.exe` e abra.
- Quem já tem instalado recebe o aviso de atualização dentro do Estúdio.
