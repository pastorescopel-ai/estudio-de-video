# Estúdio de Vídeo

Versão atual: **1.7.6**

Primeira versão com atualização automática. Legendas, música e lugares para imagem podem ser arrastados e redimensionados na linha do tempo; bolinha para mudar o tamanho da legenda, textos e stickers direto no vídeo.

- Instalar num PC novo: baixe `EstudioDeVideo-Instalador.exe` e abra.
- Quem já tem instalado recebe o aviso de atualização dentro do Estúdio.
