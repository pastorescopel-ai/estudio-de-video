# Estúdio de Vídeo

Versão atual: **1.7.7**

GIFs e stickers em alta do GIPHY (com busca) e os sons mais baixados do Freesound por categoria, prontos para colocar no vídeo.

- Instalar num PC novo: baixe `EstudioDeVideo-Instalador.exe` e abra.
- Quem já tem instalado recebe o aviso de atualização dentro do Estúdio.
